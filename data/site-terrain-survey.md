# LOTR TCG Site Card Terrain Survey

229 site cards across 15 sets (sets 9, 14, 16, 19 contained no sites).
Each card is assigned a **physical terrain category** for board layout selection.

---

## Terrain Categories (for board layout)

These are the proposed categories for choosing which board layout to display.
They describe the *physical geography* of the location, not the game-mechanic keyword.

| Category | Description | Visual Character |
|---|---|---|
| **Village/Dwelling** | Towns, inns, homes, hobbit-holes, settlements | Buildings, streets, warm interiors, lantern light |
| **Pastoral/Farmland** | Peaceful countryside, fields, gardens, the Shire | Green rolling hills, hedgerows, gardens, fences |
| **Forest** | Dense woodland, ancient trees, overgrown paths | Canopy, filtered light, roots, undergrowth |
| **Plains/Grassland** | Open flat or rolling terrain, moors, downs | Wide horizon, grass, wind, expansive sky |
| **Marsh/Swamp** | Bogs, wetlands, flooded areas, dead water | Mist, murky water, reeds, treacherous footing |
| **River/Waterway** | Rivers, fords, lakes, ferries, waterfalls | Flowing water, banks, boats, river sounds |
| **Hills/Ruins** | Exposed hilltops, ancient ruins, rocky high ground | Stone remnants, windswept, elevated views |
| **Mountain/Pass** | High peaks, snowy passes, mountain roads | Snow, rock, thin air, extreme exposure |
| **Elven Sanctuary** | Rivendell, Lothlorien -- otherworldly protected places | Golden light, waterfalls, elegant architecture, serenity |
| **Underground/Cavern** | Mines, tunnels, caverns, tombs | Darkness, torchlight, stone pillars, echoes |
| **Fortress/Fortification** | Castles, walls, gates, battlements, towers | Stone walls, battlements, siege equipment, military |
| **City/Urban** | Large cities (Minas Tirith, Edoras, Osgiliath) | Stone streets, tiered architecture, civic scale |
| **Volcanic/Mordor** | Mordor wastelands, lava, ash, desolation | Red/black sky, no vegetation, volcanic, oppressive |
| **Dark Stronghold** | Enemy fortresses (Orthanc, Minas Morgul, Dol Guldur) | Industrial, corrupted, menacing architecture |
| **Battlefield** | Active or recent combat zones on open ground | Scorched earth, siege, armies, wreckage |

## Notes on Category Decisions

### Sanctuary != Elven Sanctuary
The game keyword "Sanctuary" appears on many sites (Edoras, Helm's Deep interior, Minas Tirith circles). Only sites in Rivendell, Lothlorien, and the Grey Havens are categorized as "Elven Sanctuary" -- the others get their physical terrain (City/Urban, Fortress, etc.).

### Battleground != Battlefield
The game keyword "Battleground" is a mechanical keyword. Some Battleground-tagged sites are fortresses (Helm's Deep walls), strongholds (Orthanc), or cities (City of Kings). The "Battlefield" terrain category is reserved for actual open-field combat zones (Pelennor Fields, Wold Battlefield, Pelennor Flat, etc.).

### Mordor locations
All locations inside Mordor (Dagorlad, Slag Mounds, Narchost, Mount Doom, Morgul Vale, etc.) are "Volcanic/Mordor" regardless of whether the local terrain is technically plains, mountain, or pass. The visual character of Mordor overrides the base geography.

### Isengard as Dark Stronghold
Isengard sites (Orthanc, Wizard's Vale, Ring of Isengard, Saruman's Lab, etc.) are categorized as "Dark Stronghold" rather than "Fortress" because the visual character is industrial/corrupted, not military stone fortification.

### Brown Lands
Despite having the River keyword (it's along the Anduin), the Brown Lands are a desolate wasteland. Categorized as Plains/Grassland because the actual geography is barren open terrain.

### Window on the West
Henneth Annun is a cave behind a waterfall in Ithilien. Although it's in a forest region, the actual site is a cavern. Categorized as Underground/Cavern.

### Dimrill Dale
Though marked Sanctuary in the game (it's the relief of leaving Moria), it's physically a mountain valley. Categorized as Plains/Grassland.

### Ford of Bruinen
Although it's a Rivendell Sanctuary site, the actual location is a river ford. Categorized as River/Waterway because the board layout should show water.

### Cross Roads / Crossroads of the Fallen Kings
Both represent the road junction in Ithilien where the fallen Gondorian statue stands. The area is overgrown forest. Categorized as Forest.

## Board Layout Mapping Recommendation

For selecting which board layout to display, these 15 terrain categories could be consolidated into ~8 layout archetypes:

| Layout Archetype | Terrain Categories Covered | Visual Feel |
|---|---|---|
| **Open Field** | Plains/Grassland, Battlefield, Pastoral/Farmland | Wide horizon, lateral movement |
| **Forest** | Forest | Canopy, vertical elements, filtered light |
| **Water** | River/Waterway, Marsh/Swamp | Flowing/still water, banks, mist |
| **Mountain** | Mountain/Pass, Hills/Ruins | Elevation, rock, exposure |
| **City** | City/Urban, Village/Dwelling | Architecture, streets, interiors |
| **Sanctuary** | Elven Sanctuary | Ethereal, golden, protected |
| **Underground** | Underground/Cavern | Darkness, pillars, torchlight |
| **Fortress** | Fortress/Fortification | Walls, battlements, siege |
| **Dark Domain** | Dark Stronghold, Volcanic/Mordor | Corrupted, industrial, volcanic |
