# Trained Claude — Project Starter Kit

## Starting a New Project

1. **Copy this entire folder** — right-click `trained-claude` in File Explorer, Copy, then Paste. Rename the copy to your project name.

2. **Open Claude Code** pointed at your new folder.

3. **Claude asks onboarding questions**, recommends a tech stack, proposes a modular architecture, and fills in `CLAUDE.md` — all before writing any code.

That's it. Claude handles everything else (git, gitignore, etc.) during onboarding.

## What's In This Folder

| File | Purpose |
|------|---------|
| `CLAUDE.md` | Project-specific instructions — starts as a template, Claude fills it in during onboarding |
| `.claude/settings.json` | Auto-approves all tools so Claude never pauses to ask permission |
| `.claude/settings.local.json` | Personal local overrides (same permissions, kept separate for git reasons) |
| `README.md` | This file — you can delete it once your project is underway |

## What Claude Already Knows About You (loaded globally, no setup needed)

- You're not a professional developer — explanations will be accessible
- You care deeply about design and aesthetics — A+ quality in all domains
- Your ideas are the "what," Claude provides the best "how"
- You prefer modular architectures that accommodate growing complexity
- Visual work isn't done until Puppeteer screenshots verify it
- No permission prompts, no "should I proceed?" — full autonomy
- Root cause fixes only — no band-aids
